# 内容详情页开发计划

## Context

用户要求"开发内容详情页面,内容底部可以进行评论和查看评论"。当前项目已有:
- `src/pages/comment/comment.vue` 评论页(原帖 FeedCard + 评论区,已通过 13 条测试)
- `src/api/comment.ts` 评论 API、`src/api/feed.ts` 的 `getFeedById(id)→Promise<FeedItem|null>`
- `src/components/FeedCard.vue`(文章 excerpt 3 行截断、投票、短信息 5 行截断)

`index.vue` 的 `onCardTap` 对文章类型仅弹 toast"文章详情开发中",需改为跳转详情页。

## 用户已确认的关键决策

1. **detail.vue 与 comment.vue 并存**:detail.vue 从 FeedCard 内容点击进入(展示完整正文 + 底部评论区);comment.vue 保留,评论图标仍跳评论页。**两个页面各自内联评论逻辑(接受代码重复),不抽取共享组件、不重构 comment.vue**(保护已通过的 13 条评论页测试)。
2. **文章正文 = excerpt 不截断展示**:mock 中 `ArticleItem` 仅 `excerpt` 字段,详情页展示其完整文本(取消 FeedCard 的 `-webkit-line-clamp`)。不改 API 类型与 mock。

## 实现方案

### 1. 新建 `src/pages/detail/detail.vue`(主交付物)

**页面结构**:
- 顶部 topbar(返回箭头 `.back-arrow` 纯 CSS 45° 旋转 + 标题"详情"),与 comment.vue/search.vue 一致
- 内容区 `paddingTop: topbarHeight`:
  - 加载态(loading-dots,复用通用样式)
  - 详情卡片(白底圆角):
    - 作者信息头(头像渐变 + 用户名 + 时间 + 关注按钮)——结构同 FeedCard `.card-header`
    - 完整内容区(按 type 分支):
      - article: 大标题(无截断) + excerpt 完整正文(**去掉 `-webkit-line-clamp`**) + 封面渐变 + 标签
      - poll: 问题 + 选项(带进度条 + 投票交互 `selectedOption`/`barWidth`) + 总参与数
      - message: 完整文本(**去掉 5 行截断**)
    - 互动栏(点赞/评论/转发纯 CSS 图标 + 计数)——图标结构同 FeedCard(.ic-heart/.ic-comment/.ic-share)
  - 评论数标题"共 N 条评论"
  - 评论区(评论列表 + 楼中楼回复 + 加载更多 + 空态)——内联复用 `comment.ts` API 与 comment.vue 的评论模板/逻辑
- 底部固定输入栏(回复提示 + input + 发送按钮品牌渐变),适配 `env(safe-area-inset-bottom)`

**脚本逻辑**(setup lang="ts"):
- `onLoad(options)` 取 `id` → `init()`
- `init()`:并行 `getFeedById(feedId)` + `loadComments(true)`
- `loadComments(reset)` / `onReachBottom` 分页:复制 comment.vue 同名函数
- `onLike`(toggle `feedItem.liked` + `toggleLike`)、`onComment`(页面已有评论区,改为 `uni.pageScrollTo({ selector: '.comment-list' })` 滚动定位到评论区而非跳转)、`onShare`/`onFollow`(toast)、`onVote`(poll,`castVote`)
- `onCommentLike`/`onReplyLike`/`onReply`/`exitReply`/`onSend`/`formatTime`:复制 comment.vue 同名逻辑

**样式方案(关键,避免与 comment.vue 全局类冲突)**:
- 采用**双 `<style>` 块**:
  - `<style lang="scss">` 仅含 `page { background: #f5f5f7 }`(全局,与其它页一致)
  - `<style lang="scss" scoped>` 承载全部页面样式(参考 register.vue 已用 scoped 且 mp-weixin 构建通过)
- scoped 下复用常规类名(`.comment-list`/`.cm-avatar`/`.cm-heart`/`.input-bar`/`.ic-heart` 等)——scoped 自动加 `[data-v-xxx]`,与 comment.vue/FeedCard 的全局同名类**完全隔离**,H5 多页切换无冲突
- `uni.scss` 自动注入,可直接用 `$brand-purple`/`$button-gradient`/`@mixin flex-center`
- 纯 CSS 图标(心形两圆+方块、评论气泡+尾、转发线+箭头)按项目既有结构在 scoped 块内重写

### 2. 修改 `src/pages/index/index.vue`
- `onCardTap(item)`:将"文章详情开发中"toast 替换为 `uni.navigateTo({ url: '/pages/detail/detail?id=' + item.id })`,对所有触发 tap 的类型(article/message)生效(poll 不 emit tap,不受影响)

### 3. 修改 `src/pages/search/search.vue`
- FeedCard 增加绑定 `@tap="onCardTap"`,并新增 `onCardTap(item)` 跳转 detail(与 index 一致),使搜索结果也能进入详情页

### 4. 修改 `src/pages.json`
- `pages` 数组追加 detail 路由:
  ```json
  {
    "path": "pages/detail/detail",
    "style": {
      "navigationBarTitleText": "详情",
      "navigationStyle": "custom",
      "navigationBarTextStyle": "black"
    }
  }
  ```

### 5. 补充 `tests/scss.spec.ts`
- 新增 `describe('detail.vue SCSS 样式块')`,参考 comment.vue 测试块结构,断言:
  - 可被 dart-sass 无错编译(scoped + 全局双块,需调整 `extractStyle` 正则以匹配多个 style 块——见下)
  - page 背景浅灰、topbar fixed、back-arrow 45° 旋转
  - 详情正文区无 `-webkit-line-clamp`(确保文章/消息不截断)
  - 互动栏心形图标含三子元素且点赞态填充 `#ff5c9d`
  - 评论区 `.cm-avatar`/`.comment-author`/`.reply-list` 左竖线/`.cm-heart`/`.input-bar` fixed + safe-area/`.send-btn` 品牌渐变 + disabled 透明度
- `extractStyle` 当前正则只取首个 `<style>` 块;detail.vue 有两个 style 块,需为 detail 测试改用提取**全部** style 块(新增 `extractAllStyles` 辅助函数,或对 detail 用拼接两块的方式)。不影响其它测试。
