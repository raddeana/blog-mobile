## 数据模型（src/api/comment.ts，新建）

参照 [feed.ts](file:///d:/github/blog-mobile/src/api/feed.ts) 与 [search.ts](file:///d:/github/blog-mobile/src/api/search.ts) 的「类型 + mock + async 函数 + TODO 注释」结构：

```ts
export interface CommentAuthor { id: number; name: string; avatar: string } // avatar 空串=纯CSS默认头像

export interface Reply {
  id: number
  commentId: number
  authorId: number; authorName: string; authorAvatar: string
  content: string
  createdAt: string
  likes: number; liked: boolean
  replyToName?: string // @ 回复目标用户名（楼中楼）
}

export interface Comment {
  id: number
  feedId: number
  authorId: number; authorName: string; authorAvatar: string
  content: string
  createdAt: string
  likes: number; liked: boolean
  replies: Reply[] // 一层嵌套（移动端常见楼中楼）
}

export interface CommentQuery { feedId: number; page: number; pageSize: number }
export interface CommentResult { list: Comment[]; hasMore: boolean; total: number }
```

Mock：复用 feed.ts 的 mockAuthors 思路，为几个 feedId 生成 6-10 条评论，部分带 1-3 条回复。

API 函数（均 async + setTimeout mock + TODO 真实接口注释）：
- `fetchComments(query)` → CommentResult
- `addComment(feedId, content)` → Comment（乐观插入 mock 列表头部）
- `addReply(commentId, content, replyToId?)` → Reply
- `toggleCommentLike(commentId, liked)` → void
- `toggleReplyLike(replyId, liked)` → void

## 评论页面（src/pages/comment/comment.vue，新建）

模板/脚本/样式三段，严格参照 [search.vue](file:///d:/github/blog-mobile/src/pages/search/search.vue) 的页面骨架。**顶部展示原帖 + 下方评论列表**（微博/推特式）：

**模板**：
- 固定 `.topbar`：返回箭头（纯 CSS 45° 旋转，同 search.vue `.back-arrow`）+ 居中标题「评论」
- `.content` 内容区（paddingTop = topbarHeight）：
  - 原帖：`<FeedCard :item="feedItem" @like @comment @share @follow @vote />`（comment 事件在本页不跳转、空操作；like/share/follow/vote 复用现有逻辑）。feedItem 未加载时显示 loading-dots。
  - 加载态：复用 `.loading-dots` + `.loading-text`（同 search.vue/index.vue）
  - 空态：复用 `.empty-icon`（圆+横条）+ `.empty-text`「还没有评论，快来抢沙发」
  - 评论列表 `.comment-list`：每条 `.comment-item`
    - 左：默认头像 `.avatar-default`（复用 FeedCard `.avatar-default/.avatar-head/.avatar-body` 的纯CSS渐变+人形）
    - 右：`.comment-main`
      - `.comment-author`（品牌紫 #7b5cff）
      - `.comment-text`
      - `.comment-foot`：`.comment-time`（左）+ `.like-btn`（心形小图标+数字，复用 FeedCard 心形纯CSS结构缩小版）+ `.reply-btn`（「回复」文字）
    - 回复区 `.reply-list`（缩进 + 左侧 2rpx 品牌紫竖线 + 浅紫底）：每条 `.reply-item` 为「回复 @name：内容」+ 小点赞按钮
- 固定底部输入栏 `.input-bar`（fixed bottom + env(safe-area-inset-bottom)）：
  - 回复态：`.reply-hint`「回复 @name」+ `.cancel-reply`（× 关闭）
  - `<input>` + `.send-btn`（品牌紫粉渐变 `$button-gradient`，disabled 态降透明度）

**脚本 setup**（import FeedCard、getFeedById、fetchComments 等）：
- `onLoad` 接收 `id`（feedId，来自路由 query），并行调用 `getFeedById(id)`（填充 feedItem 供原帖展示）与 `fetchComments`（填充评论列表）
- `onReachBottom` 加载更多（同 search.vue loadMore）
- 原帖 FeedCard 事件：`onLike` 同首页 toggle、`onComment` 空操作（已在评论页）、`onShare/onFollow/onVote` 复用 toast 占位
- 评论交互：`onCommentLike`/`onReplyLike`（toggleCommentLike/toggleReplyLike）、`onReply`（进入回复态记录目标）、`onSend`（addComment 或 addReply，提交后清空输入、退出回复态、乐观更新列表）
- `onBack`：uni.navigateBack

**样式**（lang="scss"，全局非 scoped，含 `page` 选择器，背景 #f5f5f7）：
- 复用品牌变量：`$brand-purple`/`$brand-pink`/`$button-gradient`/`rgba($brand-purple, a)`
- 所有交互元素用 `hover-class` + `:hover-stay-time="80"`
- 纯 CSS 绘制：返回箭头、心形点赞图标、默认头像人形，无图片/字体
- rpx 单位；`var(--status-bar-height)` 适配状态栏；`env(safe-area-inset-bottom)` 适配底部
